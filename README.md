## 📌 About

This repository contains clean, well-commented Java implementations of core data structures and algorithms. Each topic is organized in its own folder. Solutions include time and space complexity notes where applicable.

Java is used as the primary language because of its strong typing, widespread use in technical interviews, and relevance to backend and enterprise development.

## 📚 Topics Covered

| Topic | Concepts |
|-------|----------|
| Arrays | Traversal, two-pointer, sliding window, prefix sum, Kadane's algorithm |
| Binary Search | Classic binary search, search in rotated array, search variants |
| Bit Manipulation | AND/OR/XOR tricks, bit counting, power of two checks |
| Dynamic Programming | Memoization, tabulation, classic DP problems |
| Hashing | HashMap, HashSet, frequency counting, anagram detection |
| Linked List | Singly linked list, reversal, cycle detection, merge |
| Trees | Binary tree traversal (inorder, preorder, postorder), BST |
| Two Pointers | Pair sum, container problems, sorted array techniques |

## 🚀 Getting Started

**Prerequisites:** Java 11 or above, any Java IDE (VS Code, IntelliJ IDEA, Eclipse)

**Run a single file:**
```bash
javac Arrays/SomeFile.java
java Arrays/SomeFile
```

Or open the repository as a project in your preferred Java IDE.
